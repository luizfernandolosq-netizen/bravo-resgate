BRAVO RESGATE - SITE PRONTO
===========================

1. COMO ABRIR
Abra o arquivo index.html com Chrome, Edge ou Firefox.

2. COMO PUBLICAR
Opções simples:
- Netlify Drop: arraste a pasta/ZIP para o serviço de publicação.
- GitHub Pages: envie os arquivos para um repositório e ative Pages.
- Hospedagem tradicional: envie todos os arquivos para a pasta public_html.

3. FOTOS DOS EVENTOS
O site já funciona sem fotos externas, usando artes de fundo locais.
Para usar fotos oficiais, copie-as para a pasta assets e altere no style.css:
  .event-a { background-image: ..., url('assets/SUA-FOTO.jpg'); }
Repita para event-b, event-c e event-d.

4. LOGO
A logomarca oficial da Brigada Bravo Resgate está em assets/logo-bravo-resgate.png e já está aplicada ao site.
